# D-001 采用“整站替换”而非“在 AstroPaper 上叠加”

- **状态**：已采纳
- **日期**：2026-11-01

## 背景

AstroPaper 与 Fuwari 是两套完整的 Astro 主题脚手架，目录结构、内容集合 schema、组件体系、构建配置均不同。Fuwari 不是可以通过 npm 安装到现有站点的插件型主题。

## 决策

以 Fuwari 官方仓库为基线，整体替换站点源码。

## 理由

Fuwari 官方安装方式就是基于模板创建新仓库；混合两套 `src/` 会产生大量冲突和不可维护的补丁。

## 影响

原有 AstroPaper 源码不再参与构建，但保留完整备份（见 D-002）。
