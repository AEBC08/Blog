# D-008 当时不添加 GitHub Pages 部署工作流

- **状态**：已被 D-016 取代
- **日期**：2026-11-01

## 背景

安装时项目不是 git 仓库，也没有远程地址、用户名、分支和 Pages 源配置；原 AstroPaper 站同样只有 CI 检查、没有部署工作流。

## 决策

只保留 Fuwari 自带的构建检查工作流，不凭空生成部署 YAML；把部署配置列入待办。

## 理由

部署工作流依赖具体仓库名与 Pages 设置，猜测生成容易产生错误配置；先保证本地构建可用。

## 影响

用户后来确认是 GitHub Pages 项目页，已在 D-016 添加 `deploy.yml`。
