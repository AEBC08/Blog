# D-017 将 memory 按类别重构

- **状态**：已采纳
- **日期**：2026-11-01

## 背景

最初所有记录都堆在 `memory/` 根目录（`00-overview.md`、`01-decisions.md` 等），决策、日志、指南、待办混在一起，文件变大后不便查找，也不利于后续追加。

## 决策

重构为按类别存放：

```text
memory/
├─ README.md          # 索引与约定
├─ overview.md        # 项目现状
├─ decisions/         # 一条决策一个文件 + README 索引
├─ logs/              # 按日期的操作/验证日志
├─ guides/            # 可复用指南
└─ tasks/             # 待办
```

- 决策文件命名：`D-<编号>-<短横线描述>.md`
- 日志文件命名：`YYYY-MM-DD-<主题>.md`
- 旧决策正文不改，只追加新编号；被取代时在旧文件标注状态。

## 理由

分类后每类文件职责单一，追加和检索都更容易；一条决策一个文件便于在提交或讨论中单独引用。

## 影响

旧的根目录文件已删除，内容迁移到新结构；`memory/` 仍不参与构建和部署。
